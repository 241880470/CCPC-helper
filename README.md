# CCPC 模拟训练助手 · 训练优化版

桌面版队伍训练工具：导入真实题库 → AI 组卷 → 确认开赛 → 记录与核对成绩 → AI 复盘。此包为 Python 源码，不含 Windows exe，也未附带题库。

## 第一次使用（Windows）

1. 解压到可写目录，例如 `D:\CCPC-helper`，不要直接在压缩包中运行。
2. 安装 Python 3.10+（建议 3.11/3.12），勾选 Python launcher 和 Tcl/Tk；CF 浏览器与题面功能还需要 Microsoft Edge。
3. 双击 `install.bat` 安装依赖，再双击 `start.bat`。
4. 在首次配置窗口填写自己的 API Key，选择 DeepSeek / OpenAI / 自定义服务及模型。CF 登录信息选填；也可稍后设置。以后从「设置」修改，保存即生效。
5. 点击菜单「导入题库」，选择提供者给出的 `problem_bank.json`。没有题库时，可在项目目录运行 `.venv\Scripts\python.exe build_problem_bank.py` 尝试抓取。CF 可能限流或要求访问权限，抓取不保证成功。

**缺少、损坏或数量不足的题库会阻止组卷，不再自动让 AI 编造题名和链接。** 初始没有补充题库数据。

## 完成一场训练

1. 在赛前准备区填写题数（10～12）、时长（1～1440 分钟）和参赛 CF 账号。多人账号用逗号分隔，最多 10 个；可留空并手工记录成绩。
2. 点击「生成模拟赛」。组题在后台运行，重复点击被禁用；生成成功后停在**赛前准备**，不会计时。
3. 可选：点击「生成中文题面 PDF」，等待抓取、AI 翻译和生成完成。PDF 保存在程序目录；也可直接通过题目链接练习。
4. 准备好后点击「开始比赛」，核对题数、时长和账号再确认。计时按真实时间计算，关闭程序不会暂停。开始后账号和时长固定，避免改变统计口径。
5. 每道题都可填写结果、负责队员、耗时和备注。整体备注和逐题记录会自动保存。任务进行时记录暂时锁定，仍可查看题目。
6. 点击「抓取评测结果」查询本场各账号的提交；抓取失败不影响手工记录，部分账号失败会提示。
7. 时间到后，核对各题状态，点击「确认结果并复盘」。也可提前结束；如果在比赛进行中提交复盘，会先确认结束本场。
8. 复盘完成后，可从「查看报告」查看结果。报告、历史、队伍记忆和当前训练均会保存。

组题、复盘、PDF 和 CF 查询在后台运行，显示进度。任务失败后可重试；修改训练记录后，需重新点击相应操作，避免把旧数据的重试结果应用到新记录。

## 结果怎么计算

- **自动**：根据本场账号的有效提交记录推导；窗口内出现过 AC，就保持通过，不被后续 WA 覆盖。
- **AC / 尝试未过 / 未做 / 待确认**：人工确认，优先于自动结果，后续抓取不会覆盖。改回「自动」即可重新使用提交记录。
- **待确认**：没有足够数据，或者只有尚未完成评测的记录。不会直接当作未做，也不会要求 AI 据此认定能力不足。
- 耗时是用户填写的训练观察值，可留空；填写时须为非负数字。
- 多账号提交合并，重复抓取替换对应账号快照，不会不断追加相同记录。
- 提交窗口为**开赛时刻至正式结束 + 宽限时间**，且不查询未来提交。提前结束则按提前结束时刻截止并加宽限。
- 宽限默认 2 分钟，可在 `config.py` 中将 `VERDICT_GRACE_MINUTES` 设为 0，严格按正式时长统计。宽限内的提交会标明超时；超过宽限的补题不计入本场。

## 自动保存和恢复

- 备注及逐题修改约 350 毫秒后自动保存；写入失败时界面会提示，并保留内存中的修改供重试。
- 主存档是 `memory/current_contest.json`，包含赛卷、阶段、时长、开赛时间、账号、备注、人工结果、提交记录及复盘结果。
- 数据采用临时文件写入后替换，保存上一份可读的 `.bak`。当前 JSON 损坏时尝试读取备份，两份都不可读时会提示，不能保证恢复尚未落盘的最后一次输入。
- 重启后可恢复：未开始的场次仍在准备状态；进行中的场次按原时间继续；已到期的场次进入赛后状态。
- 生成新赛卷时会保留上一场存档，复盘后也会保存到 `memory/sessions/`。菜单「恢复训练存档」可载入这些 JSON。
- 兼容旧版赛卷，尽量从旧提交日志恢复记录；旧版没有保存的备注无法补回，开始时间未知时需手动核对成绩。
- 复盘成功取得但落盘失败时，分析会保留供继续保存；同一场写历史时按场次 ID 更新，避免重试产生重复记录。
- 历史记录不再自动截断为 30 场。请定期在退出程序后备份 `memory/`。

## 导入题库

支持题目数组，或包含 `problems` 数组的 JSON 对象；支持 UTF-8 / UTF-8 BOM，文件不超过 25 MB。每题至少包含：

```json
{
  "title": "真实题名",
  "source": "真实比赛名称",
  "url": "https://codeforces.com/gym/比赛ID/problem/A"
}
```

上例仅说明字段，比赛 ID 和题名必须替换为真实数据，不是可用题库。`id`、`gym_id`、`letter` 缺失时可从有效链接补齐；已有值须与链接一致。`tags` 可为字符串数组；`accepted_teams`、`total_teams` 可为非负整数。

导入前检查字段、单题链接、重复 ID/链接及统计格式。有旧题库时可选择合并或替换；同 ID 的新条目覆盖旧条目。校验失败不替换旧题库，成功替换时保留上一份可读的 `.bak`。

**导入校验仅验证格式与一致性，不联网证明题目真实、可访问或来源描述准确。** 这些仍由题库提供者和 Codeforces 页面确认。

## 连接配置和密码

日常无需手动编辑文件。配置保存在程序同目录的 `settings.json`，模板为 `settings.example.json`。格式损坏时仍可进入修复窗口，保存前备份原文件为 `settings.invalid-时间.json`。

| 项目 | 用途 |
| --- | --- |
| `API_KEY` / `BASE_URL` / `MODEL` | AI 密钥 / 兼容接口地址 / 模型，默认 DeepSeek |
| `CF_HANDLE` / `CF_PASSWORD` | Edge 登录时预填的账号 / 密码；参赛查询账号在赛前单独设置 |
| `CF_API_KEY` / `CF_API_SECRET` | 补充原场统计等维护工具所用的官方 API 凭据 |

- API Key、CF 密码与 API 凭据默认掩码显示，可选择显示。
- CF 密码默认只在本次运行使用，勾选「记住 CF 密码」才写入文件。取消勾选并保存，会删除已保存密码。
- 已保存的密钥和密码为本地明文。主窗口「CF 登录」会打开 Edge 预填信息，登录确认和验证码仍需使用者手动完成。
- 环境变量优先于本地文件。AI 三项变量名为 `CCPC_AI_API_KEY`、`CCPC_AI_BASE_URL`、`CCPC_AI_MODEL`；CF 各项变量与配置项同名。由环境变量管理的字段只读。
- AI 请求由服务商计费，队伍记忆、题目、结果和备注会用于分析；PDF 翻译会发送题面。保存配置不实际测试连接，组题等操作时才发起请求。

## 其他运行方式与维护

macOS / Linux 可手动运行（Linux 需要带 Tkinter 的 Python）：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

浏览器代码使用 Edge 通道，相关功能需要安装系统版 Microsoft Edge；仅安装 Playwright 包不会安装 Edge。

| 文件 | 作用 |
| --- | --- |
| `main.py` | 桌面界面及流程 |
| `training_session.py` | 比赛阶段、时间窗、结果合并 |
| `background_tasks.py` | 后台任务和线程消息 |
| `bank_manager.py` | 题库校验与导入 |
| `storage.py` / `memory_manager.py` | 原子保存、备份、历史和报告 |
| `contest.py` / `analyser.py` / `AI_agent.py` | AI 组题、复盘、接口调用 |
| `settings_dialog.py` / `settings_store.py` | 首次配置和设置保存 |
| `cf_submit.py` / `statement_pdf.py` | CF 浏览器流程 / 题面 PDF |
| `build_problem_bank.py` | 增量抓题；`--rebuild` 重建，`--gyms ID,ID` 指定场次 |
| `fetch_stats.py` / `fetch_tags.py` / `fetch_tutorial_tags.py` | 补充统计和标签；部分需要凭据或 AI 用量 |
| `recover_round.py` | 从已有 PDF 补录比赛，参数见 `--help`，支持 `--dry-run` |
| `tests/` | 本地自动检查，需先安装运行依赖；GUI 检查需要桌面或 Xvfb |
